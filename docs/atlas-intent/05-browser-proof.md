# 5 · The exact browser URL for every thing, because proof is a screenshot

Part of [What an atlas must be](../atlas-intent.md).

Proofs lean heavily on browser screenshots, so an atlas knows the links to every place worth looking. Asked
to fetch the organisation's policies from the compliance platform, an agent **should know the exact URL to
open in the browser** to take that screenshot. The shape the owner landed on: a screenshot of every page,
every sub-page and every setting, recording every value along the way, so the full state is held locally
and **the URL to go to** for any control is a lookup.

**The atlas holds the screenshots themselves, not only the URL** — the owner's ruling. The reason the owner
gave is a reader, not an archive: it lets the agent look at a page without piloting a browser to get there.
The owner also mused that a human-facing view of an atlas might be worth having; that is an idea the owner
floated, not a task, and nothing should be built toward it until the owner asks.

The compliance multiplier is why this earns its cost: proof-of-problem and proof-of-solution come from
the same stored link.
