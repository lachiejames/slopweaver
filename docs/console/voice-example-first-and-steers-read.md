# An example first, and the owner's steers read before a question

The owner wants the voice to preempt what it would otherwise have to be told every time: an example that changes
halfway through is hard to follow, and a question the owner's last week of steers already answers should not be asked.

- **An explanation opens on one concrete example** from what was read, unprompted, and keeps it to the end; a second
  is named as a second.
- **Before a judgement question** (an options pick, an alignment question) the thinking model reads the left-off
  block, `recent_steers` at its 168-hour ceiling, an all-time `recall` and `profile show`: what they answer is said
  back in the owner's words, and only what they leave open is asked. The owner's own "what now" reopens a choice, so it still gets
  its options, the owner's steer as the lean.

Prompt policy in `src/talk/exampleAndSteersLines.ts`, sitting before the alignment and options bullets because both
owe a question. Proven by unit tests over the prompt; a call transcript showing both is still owed.
