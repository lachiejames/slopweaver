# Rule 7 · No walls of text

Part of [Why each standing rule says what it says](../doctrine-rationale.md).

**7 · No walls of text, ever, on any outbound surface.** A message the bot sends must be **concise by
default, with everything else collapsed** behind something the reader chooses to expand. The owner has never
wanted to receive a wall of text from the bot and has said so as a doctrine, not a preference. This is not
about brevity for its own sake: an unexpanded wall is a message the owner will not read, so a bot that sends one has
not communicated, whatever it wrote.

Two consequences that are the actual rule rather than restatements of it:

- **Shape is enforced by the SCHEMA, never by review.** An outbound form caps the part that appears above the
  fold, and it **refuses** a violation rather than truncating one — a silently shortened message reports
  success while having dropped its point. If a shape can be expressed, it will eventually be sent, so a
  rejected shape must be unrepresentable in the type rather than merely undocumented.
- **Progressive disclosure is the default arrangement, not a formatting flourish.** The outcome goes above the
  fold; the evidence, the workings and the provenance go below it.

This one is stated here rather than in a memory for the same reason as the rest: it is re-injected as
instructions every session, and a rule that loads softly is a rule that gets re-argued.
