# The recurring-failure register

**What this file is.** Every failure class this system has repeated often enough to be worth a GATE, with the
evidence that proved it and — just as important — every class an adversarial pass KILLED, with the reason.
It exists so nobody ever re-mines the transcript history to re-derive friction that is already written down.

**Read the refutations before proposing a gate.** Thirty-six classes [below](./recurring-failure-register/refuted-and-seed-candidates.md) were refuted, several because a gate
ALREADY refuses them. Re-proposing one is the exact waste this file prevents.

## Where the evidence lives, and why it is not here

This file is SHAPE, so it commits. The verbatim anchors are CONTENT — they quote real threads and carry
teammate logins and workspace ids — so they live UNCOMMITTED at
`$SLOPWEAVER_HOME/registers/recurring-failure-anchors.json`, keyed by the class names on the pages listed below. That split is
[the partition](constraints/partition.md), and it is not optional: the hygiene gate was run over the anchors
and reported denylist and raw-workspace-id hits, while the classes themselves came back clean. Verify with
`yarn tsx src/cli/index.ts dev gate` after staging any file you add here.

## How it was mined, once

A 29-day window (the transcript retention floor) over 1,554 session transcript files in both repos, reduced to
**6,119 real typed turns** — the owner’s words plus supervisor relays — by stripping retrieval provider prompts and
compaction summaries, which are injected in the user role and were **71% of the raw bytes**. Split 20 ways, plus
four lanes over the daily self-improvement reports, the morning audits, ~796 filed handover docs clustered by
repeated incident shape, and a memory/canon cross-reference for prose rules that have a feedback memory but no
gate. That produced **164 candidates carrying 622 anchored instances**, clustered to 67 classes, of which an
adversarial pass — every verifier told to default to REFUTING, and to open the file before calling a seam real —
killed 36.

**This pass is not repeated.** The daily self-improvement loop (`slopweaver reflect brief`, `$SLOPWEAVER_HOME/morning/`)
catches what happens from here; it runs every 24h and never needed the back-catalogue. This register is the saved result, so nobody has to fan out over old
transcripts again to rederive the friction points.

**Counts are floors.** Retention is 29 days; only the owner’s side of the conversation was read, so a failure the
owner never commented on does not appear; and at least one count is inflated by construction —
`door-gate-fires-only-at-post-time-after-the-work-is-spent` counts 4 instances that the verifier traced to ONE
incident chain on one night. Rank that one on cost-per-hit, not frequency.
