# Why each standing rule says what it says

The WHY behind `AGENTS.md`'s rules. Every paragraph here exists because a rule had already been re-argued,
misread or quietly broken once, so none of it is decoration — but none of it changes what a session must
DO either. `AGENTS.md` keeps the numbered rules and the gate that enforces each one, and links here for the
reasons. Read a section before proposing a change to its rule: the reasoning is what stops the same
argument being had a third time.
