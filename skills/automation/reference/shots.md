# A digest row that carries pictures

The seated half of the `datadog-alert-digest` kind — the one a tick may not run, because the captures are
taken in THE OWNER'S OWN CHROME and no tick may drive a browser unattended (`AGENTS.md` rule 2).

The three daily alert digests post cropped, annotated Datadog images. Such a row is seated rather than run in the tick, and the run is two commands with your own capture
work between them.

```bash
slopweaver automation run-due --recipe growth-ops --claim-id <token> --dry-run   # the card, and its shot list
slopweaver browser shot --url '<the printed target>' --caption '<the printed title>' --out <printed path> --json
slopweaver browser image-record --... # the readback that admits the bytes, per skills/loop-bot/reference/visual-evidence.md
slopweaver automation run-due --recipe growth-ops --claim-id <token> --media a.png,b.png
```

- The dry run prints one `shot <n>` line per FIRING view — red and orange only, deduped, each citation
  already rewritten to the timeseries view its adapter covers — plus a `no shot` line for any firing item
  whose citation no adapter covers. It posts nothing and stamps nothing.
- **A firing `logs-facet-sum` row prints `no shot`, never a command** — its row sums an attribute while the
  chart counts log lines (2,569 against 30), so no capture of it could reconcile. Its citation carries
  `agg_t=sum`, which is how the card alone says so; there is no browser walk to take for it.
- **Read each capture's own number against the item beside it, and drop what will not reconcile.** A
  citation is the search its author declared, so it can be BROADER than the item (growth-ops cites one
  skipped search from three probes, so the chart counts about 1,322 where the row reads 298). The caption
  names every item a shared view covers; the judgement about attaching it is yours.
- **The card is never held for a picture.** A capture that refuses is an image the card does without, and the
  real run prints `N image(s) attached for M firing view(s)` so a mismatch is visible rather than silent. The
  promise is a digest within 24 hours; an image that will not grade does not get to break it.
- Only a capture that PASSED its readback can be attached — `slack post` refuses an unrecorded image, which
  is a rail and not something to work around.
